Machine output status

Mach3 G-code: not enabled. A verified machine profile, origin, axis directions, tool table, spindle control and dry-run validation are required first.

WoodWOP: planned as a separate DXF / supported WoodWOP workflow. This starter does not create MPR/MPRX files.

Edge banding: core-board dimensions are automatically reduced by the selected tape thickness on each selected edge. Finished dimensions remain as entered.

Hinge drilling: adjustable planning coordinates are shown on panel drawings. Confirm every dimension against the exact hinge manufacturer template before drilling; this is not CNC-ready output.

Panel-saw optimizer: a guillotine-style heuristic planner is included. It groups by material and thickness, considers core dimensions, kerf, trim and grain restrictions, and reports sheet layouts and unplaced parts. It is a planning aid, not a validated saw cut sequence.

Install D3 SmartCut on iPhone

  1. Open this address in Safari.
  2. Tap the Share icon.
  3. Choose Add to Home Screen.
  4. Keep the name D3 SmartCut and tap Add.

Sign in through the workshop access page when prompted. After the first successful load, the app shell can open offline; project data remains on this iPhone.
